## 📋 Sobre o Projeto

O **NEA-Mutiró** é o site institucional do Núcleo de Estudos em Agroecologia e Bem-Viver, um projeto de extensão do **CEFET-MG** em parceria com a **UEMG** e a **FIOCRUZ Minas**.

O núcleo articula **ensino, pesquisa e extensão** para fortalecer práticas agroecológicas junto a comunidades quilombolas, indígenas e periferias urbanas em Minas Gerais, unindo o conhecimento acadêmico aos saberes tradicionais.

### 🎯 Objetivos

- Divulgar as ações e projetos do NEA-Mutiró nos territórios parceiros
- Apresentar as comunidades atendidas e suas histórias de resistência
- Facilitar o contato entre a comunidade acadêmica e os territórios
- Servir como vitrine institucional para futuras parcerias e financiamentos

## 🌍 Territórios Atendidos

| Território | Localização | Foco |
|---|---|---|
| **Aglomerado Cabana do Pai Tomás** | Belo Horizonte (MG) | Agricultura urbana, segurança alimentar |
| **Aldeia Indígena Kamakã Mongoió** | Brumadinho (MG) | Reflorestamento, etnoecologia |
| **Quilombo Córrego do Narciso** | Araçuaí (MG) | Agroecologia, sementes crioulas |

## 📁 Projetos

- 🌿 **Hortas Comunitárias Urbanas** — Implementação de espaços produtivos em periferias urbanas
- 🌽 **Manejo de Raízes Nativas** — Estudo de técnicas sustentáveis com comunidades tradicionais
- 🤝 **Troca de Saberes** — Rodas de conversa entre conhecimento tradicional e acadêmico
- 📚 **Formação em Agroecologia** — Capacitação de jovens agricultores em tecnologias sociais

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/Alexsander532/nea-mutiro-site.git
cd nea-mutiro-site

# Instale as dependências
npm install

# Execute em modo desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

### Comandos disponíveis

| Comando | Descrição |
|---|---|
| `npm run dev` | Inicia servidor de desenvolvimento |
| `npm run build` | Gera build de produção |
| `npm run start` | Inicia servidor com build de produção |
| `npm run lint` | Executa verificação de lint |
